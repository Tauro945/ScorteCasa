Aggiungi o modifica prodotti

Categorie

Aggiungi, rinomina o elimina macrocategorie e sottocategorie. Una categoria che contiene prodotti non si può eliminare: spostali prima con Modifica nella lista sopra.

Backup

I dati restano in questo browser. Per spostarli o salvarli, genera il backup: viene scaricato un file .json. Per ripristinare, premi Ripristina da file e scegli il .json. Il ripristino sostituisce i dati attuali.
